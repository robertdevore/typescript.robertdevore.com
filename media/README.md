# Course launch image

`typescript-course-launch.png` is a 1536 × 1024 image for sharing the course on social media.

Created on September 6, 2026 with the built-in image-generation tool, using the user's Rust course launch graphic as a visual reference. The TypeScript version uses blue accents, 36 lessons, and the production course URL. The lettering follows the reference's pixel monospace style; it is rendered artwork, not embedded font files.

The build copies this image to `/assets/typescript-course-launch.png` for the homepage's Open Graph, Twitter, and structured-data preview. Lesson and build pages retain their own cards.
